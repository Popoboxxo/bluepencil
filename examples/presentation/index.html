Einführung

Diese Seite ist ein einzelnes HTML-Dokument mit angehängtem bluepencil-Review-Layer. Es verwendet localStorage als Speicher — kein Backend nötig.

So funktioniert es

Ein einzelner <script>-Tag lädt attach.js, das das Custom Element <bluepencil-notes> definiert und den Layer automatisch an document.body anhängt.

Export / Import

Notizen überleben Reloads und lassen sich als JSON exportieren und auf einem anderen Browser importieren. Kein Server, keine Datenbank.
