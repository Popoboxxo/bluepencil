## 2. Verdict und Gewichtung

**CHANGES_REQUESTED.** Die AC-Abdeckung ist vollständig und widerspruchsfrei (157/157, keine Dublette, keine
erfundene ID), die Merge-Reihenfolge stimmt wörtlich mit Spec §3.12 überein, und die Eigentumsmatrix hält die
drei benannten Ausnahmen ein. Blockierend sind fünf mechanische Brüche, die dazu führen, dass einzelne ACs in
dem Commit, dem der Plan sie zuweist, **nicht grün werden können** — der Plan behauptet das aber (§9, §6.1,
Annahme A5).
